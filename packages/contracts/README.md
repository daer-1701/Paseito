# Contratos compartidos

Documenta aquí los modelos y endpoints que usan dos o más aplicaciones.
Mantén un contrato legible y versionado, por ejemplo OpenAPI o JSON Schema.

Primeros contratos por acordar:

- PaseoYa → Jarvis: productos, negocios, promociones y disponibilidad.
- Paseo Points → Jarvis: consulta autenticada de saldo y recompensas.
- Identidad compartida: identificador de usuario y forma de pasar una sesión,
  sin compartir credenciales entre servicios.
