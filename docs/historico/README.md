# Fuentes históricas

`directorio-companero.json` conserva el directorio original de 74 lugares, antes
ubicado en backend/app/datos/lugares.json. Sus datos útiles están incorporados a
los bundles versionados de Jarvis. No se carga al arrancar ni sustituye el catálogo
activo. El importador antiguo y el servidor retirado permanecen recuperables en Git.
